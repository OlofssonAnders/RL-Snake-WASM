Reinforcement Learning with Snake

This is a demonstration of how reinforcement learning can be used to play classic games such as Snake! The game has simple rules and the set of possible actions is small. It's simple enough to be implememted in a few lines of code and is therefore a perfect candidate for testing out reinforcement learning models.

The game is rendered using Macroquad, which is an easy to use game engine for rust. The game logic and visual design is a direct copy of one of the examples listed on their website.

I started by implementing a random agent just to iron out any issues with the interface between the game and my RL code. Unsurprisingly, the random agent doesn't play very well. In order to get a good baseline to compare models to, I decided to implemented the "heuristic" agent afterwards. I then implemented progressively more complex agents in the rust programming language. All code is available here. The demos were compiled to WebAssembly, as macroquad provides excellent support for this. This is significantly faster than javascript and allows the demos to run more smoothly.

The agents presented below are:

  1. Random Agent
  2. Heuristic Agent (Following predefined rules)
  3. Pre-trained Q-Learning Agent
  4. Deep Q-Learning (Not completed)
  5. User Input (If you want to try it yourself)

Random Agent

At each time step, the random agent chooses one of the five possible actions (up, down, left, right or wait) at random.

Heuristic Agent

The heuristic agent uses hand-written rules. It's programmed to move directly towards food. Defining rules to prevent the snake from colliding with itself or ensnare itself was difficult, and I eventually gave up on the idea as it happens to exemplify the big issue with this approach in general: In addition to zero generalization, rules quickly become complex and dificult to integrate into the model.

As can be seen in the demo, the heuristic agent eventually it runs into itself. It will do this over and over again as the implementation does not have any kind of learning. On average, the heuristic agent will score higher than the random agent, but it is still far from optimal. Heuristic agent implementation details

Q-Learning

Q-learning is an algorithm that learns which actions are most valuable in different states of the game, allowing the agent to approximate an optimal policy (playing strategy). The most valuable action is the action that maximizes the expected future reward (Over multiple steps into the future). In this context, reward is a value that the agent receives for each action it takes. It is dictated by the environment and is therefore external to the agent.

It is important to specify what constitutes a good reward. For this game, keeping the snake alive should be rewarding. It should also be rewarding to collect food. After a bit of experimentation, the reward function (returning a reward given an action and state) for the snake game was defined as follows:

  • Colliding and dying: -1.0
  • Collecting food: 50.0
  • Reducing distance to food: 10.0
  • Doing nothing of the above: -0.001 (This was added to prevent the snake from circling indefinitely)

The algorithm works by storing and updating values for state-action pairs. Each value estimates the expected cumulative future reward from taking that action ,in that state, and behaving optimally thereafter. They are constantly updated as the agent explores the environment and receives feedback in the form of rewards.

The states presented to the agent do not capture all information available from the game. They are only simplified portions of the complete game states. The number of unique states to consider given all the available information, even in a small game like Snake, would become too large to handle if used. Therefore the number of states that the agent is exposed to is reduced by considering only the most useful pieces of information.

Similar to how it is important to define a good reward function, it is also important to define a good state representation. The states are what the agent "sees" and bases its decisions on. The state representation I used is the following:

  • There is a wall or body segment (aka obstacle) immediately above the head, below, to the left, or to the right
  • The food is above, below or on the same row as the head
  • The food is to the left, right or on the same column as the head

The procedure that computes how the state-action pairs should be updated for each step is not overly complicated and is not computationally demanding. see Q-Learning algorithm. This agent, playing snake below, was trained by playing the game 30 000 times. In the demo, it has been configured to always choose the action that is deemed to yield the highest future reward as opposed to making ocasional "explorative" actions. Deep Q-Learning (Deep Q-Network)

Deep Q-learning, or Deep Q-Network (DQN), is similar to regular tabular Q-learning but involves neural networks. The tabular Q-learning agent often ensnared itself since it couldn't see the full body of the snake. With Deep Q-learning, the entire board could be the state presented to be model. By using a CNN to interpret the board, it will not be too demanding in terms of computation. Deep Q-Network
