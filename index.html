Reinforcement Learning with Snake

This page demonstrates several different approaches to controlling the same Snake environment.

1. Random Agent

We begin with the simplest possible controller. The random agent chooses an action without attempting to understand the game state.

2. Heuristic Agent

The heuristic agent uses hand-written rules. It can move toward food and avoid immediate collisions, but it has not learned anything from experience.

3. Q-Learning

This agent instead learns estimates of the value of actions in different states through repeated interaction with the environment.
